# 매일 묵상 사이트 관리 방법

사이트 주소:

https://accompanywithJesus.github.io/github.io/

이 저장소는 매일 묵상 웹사이트의 파일을 보관하는 곳입니다.

## 파일 역할

- `index.html`: 화면 구조
- `styles.css`: 디자인
- `script.js`: 버튼, 음악, 기록 저장 동작
- `data/devotions.js`: 날짜별 묵상 내용
- `assets/`: 배경 음악 같은 파일

## 매일 묵상 추가하는 방법

1. GitHub에서 `data/devotions.js` 파일을 엽니다.
2. 오른쪽 위 연필 버튼을 눌러 편집합니다.
3. 맨 아래 마지막 묵상 덩어리 뒤에 쉼표를 넣고, 새 묵상 덩어리를 추가합니다.
4. 아래 초록색 `Commit changes` 버튼을 누릅니다.
5. 1-3분 뒤 사이트에 반영됩니다.

## 새 묵상 템플릿

아래 모양을 복사해서 `window.DEVOTIONS = [ ... ];` 안에 추가하면 됩니다.

```js
{
  date: "2026-05-24",
  day: "주일",
  title: "묵상 제목",
  scripture: {
    text: "성경 본문 내용을 여기에 적습니다.",
    reference: "성경 장절",
  },
  meditation: [
    "묵상 첫 번째 문단입니다.",
    "묵상 두 번째 문단입니다.",
    "필요하면 문단을 더 추가합니다.",
  ],
  todayLine: "오늘의 한 줄을 여기에 적습니다.",
  prayer:
    "기도문을 여기에 적습니다.",
},
```

## 중요한 규칙

- 날짜는 `YYYY-MM-DD` 형식으로 적습니다. 예: `2026-05-24`
- 문장은 큰따옴표 `"` 안에 넣습니다.
- 문장 안에 큰따옴표를 꼭 써야 하면 앞에 역슬래시를 붙입니다. 예: `\"아버지여\"`
- 각 묵상 덩어리 끝에는 쉼표 `,`가 필요합니다. 단, 맨 마지막 하나는 쉼표가 없어도 됩니다.
- 사이트는 오늘 날짜와 같은 묵상이 있으면 자동으로 보여줍니다.
- 오늘 날짜 묵상이 없으면 가장 마지막에 들어간 묵상을 보여줍니다.

## 배경 음악

앱은 아래 두 파일명 중 하나를 찾습니다.

- `assets/background-prayer.m4a`
- `assets/하루 시작 전 5분 기도반주 _ 5 minute for pray.m4a`

음악을 바꾸려면 `assets` 폴더에 새 파일을 올리고, `script.js`의 `musicSources`와 `index.html`의 `<source>` 경로를 바꾸면 됩니다.

## 사용자 기록은 어디에 저장되나요?

사용자가 남긴 기록은 GitHub에 저장되지 않습니다.

각 사용자 휴대폰이나 컴퓨터의 브라우저 안에 날짜별로 저장됩니다. 그래서 사용자는 같은 기기와 같은 브라우저로 다시 접속하면 자신의 기록을 볼 수 있습니다.
